Methoden der Klasse String

Sandbox

    .trim() Methode

    Entfernt Leerzeichen (Spaces, Tabs) am Anfang und Ende eines Strings. Die Mitte bleibt unverändert.

    let clean = text.trim(); // " Ala " → "Ala"
    .toUpperCase() Methode

    Gibt einen neuen String zurück, bei dem alle Buchstaben in Großbuchstaben umgewandelt sind. Das Original bleibt unverändert.

    let big = text.toUpperCase(); // "ala" → "ALA"
    .toLowerCase() Methode

    Gibt einen neuen String zurück, bei dem alle Buchstaben in Kleinbuchstaben umgewandelt sind. Nützlich vor Vergleichen.

    let small = text.toLowerCase(); // "ALA" → "ala"
    .length Eigenschaft

    Gibt die Anzahl der Zeichen im String zurück (einschließlich Leerzeichen). Achtung: Das ist eine Eigenschaft — ohne Klammern!

    let len = text.length; // "abc" → 3 (ohne Klammern!)
    .includes() Methode

    Prüft, ob ein String ein bestimmtes Fragment enthält. Gibt true oder false zurück. Groß-/Kleinschreibung wird beachtet!

    let found = text.includes("java"); // Groß-/Kleinschreibung beachten!
    .split() Methode

    Teilt einen String in ein Array anhand eines Trennzeichens. split("") — jedes Zeichen einzeln.

    let arr = text.split("-"); // "a-b-c" → ["a","b","c"]
    .join() Array-Methode

    Verbindet Array-Elemente zu einem einzelnen String und fügt das angegebene Trennzeichen dazwischen ein.

    let str = arr.join("."); // ["a","b","c"] → "a.b.c"
    split→reverse→join Kette

    Text umkehren — eine Kette aus drei Methoden: in Zeichen aufteilen, Array umkehren, wieder zusammenfügen.

    let rev = text.split("") .reverse() .join("");
    .replaceAll() Methode

    Ersetzt alle Vorkommen eines bestimmten Fragments durch einen anderen Text.

    let fixed = text.replaceAll("bug", "***"); // ersetzt JEDES Vorkommen
    .replace() Methode

    Ersetzt nur das erste Vorkommen eines bestimmten Fragments. Der Rest bleibt unverändert.

    let fixed = text.replace("error", "OK"); // ersetzt NUR das erste
    .slice() Methode

    Extrahiert einen Teil des Strings vom Index Start bis Ende (ohne Ende). Indizes beginnen bei 0.

    let part = text.slice(0, 4); // "JavaScript" → "Java"
    ⚡ Eigenschaft vs Methode

    Häufiger Schülerfehler! Eine Eigenschaft hat keine Klammern, eine Methode hat immer ().

    ✓ text.length — Eigenschaft, OHNE Klammern
    ✓ text.toUpperCase() — Methode, Klammern erforderlich
    ✗ text.length() — FEHLER!
    ✗ text.toUpperCase — FEHLER! (Klammern fehlen)
    // Merke: .length ist die EINZIGE // Eigenschaft auf diesem Spickzettel. // Alles andere ist eine Methode mit ().
