Ereignislabor

Ein Ereignis (Event) ist ein Signal dafür, dass etwas passiert ist — ein Klick, ein Tastendruck oder das Absenden eines Formulars. Diese Seite ist vollständig instrumentiert: Jede deiner Interaktionen wird live an den Monitor auf der linken Seite übertragen. Probiere die 12 häufigsten Ereignisse aus und beobachte, wie sie ausgelöst werden.

Ereignismonitor

gesamt: 0
  • Ich lausche… führe unten eine beliebige Aktion aus.
click

Ein einzelner Klick auf ein Element — das häufigste Ereignis im Web.

Klicks: 0
btn.addEventListener('click', () => { … });
dblclick

Zwei schnelle Klicks hintereinander auf dasselbe Element.

Warte auf einen Doppelklick…
box.addEventListener('dblclick', () => { … });
keydown

Eine Taste wurde gedrückt (aber noch nicht losgelassen).

gedrückt: —
input.addEventListener('keydown', e => e.key);
keyup

Eine Taste wurde losgelassen — das physische Freigeben der Taste.

losgelassen: —
input.addEventListener('keyup', e => e.key);
change

Der Feldwert wurde geändert und das Feld verlor den Fokus (oder eine Option wurde ausgewählt).

Noch nichts ausgewählt
sel.addEventListener('change', e => e.target.value);
input

Reagiert auf jedes Zeichen — fortlaufend während der Eingabe.

Zeichen: 0
input.addEventListener('input', e => e.target.value);
focus

Das Element erhielt den Fokus (z. B. nach einem Klick oder mit der Tabulatortaste).

inaktiv
input.addEventListener('focus', () => { … });
blur

Das Element verlor den Fokus — an anderer Stelle wurde geklickt.

Feld fokussieren und wieder verlassen…
input.addEventListener('blur', () => { … });
mouseover

Der Mauszeiger hat den Bereich des Elements betreten.

Bewege den Mauszeiger hierher
box.addEventListener('mouseover', () => { … });
mouseout

Der Mauszeiger hat den Bereich des Elements verlassen.

Bewege den Mauszeiger hierher und dann wieder weg
box.addEventListener('mouseout', () => { … });
submit

Das Formular wurde abgesendet. preventDefault() verhindert das Neuladen der Seite.

Das Formular wurde noch nicht abgesendet
form.addEventListener('submit', e => { e.preventDefault(); // nicht neu laden });
load

Die gesamte Seite (einschließlich Bilder und Ressourcen) wurde vollständig geladen. Dieses Ereignis wurde beim Start einmal ausgelöst.

Wird geladen…
window.addEventListener('load', () => { … });
Tipp: Im Monitor siehst du den Typ des Ereignisses, sein Ziel (e.target) und den Auslösezeitpunkt. Jedes der 12 Ereignisse wurde mit addEventListener(Typ, Funktion) verbunden.
