Sandbox

    .trim() method

    Removes whitespace (spaces, tabs) from the beginning and end of a string. Does not change the middle.

    let clean = text.trim(); // " Ala " → "Ala"
    .toUpperCase() method

    Returns a new string with all letters converted to uppercase. The original stays unchanged.

    let big = text.toUpperCase(); // "ala" → "ALA"
    .toLowerCase() method

    Returns a new string with all letters converted to lowercase. Useful before comparisons.

    let small = text.toLowerCase(); // "ALA" → "ala"
    .length property

    Returns the number of characters in a string (including spaces). Note: it's a property — no parentheses!

    let len = text.length; // "abc" → 3 (no parentheses!)
    .includes() method

    Checks whether a string contains a given fragment. Returns true or false. Case-sensitive!

    let found = text.includes("java"); // case-sensitive!
    .split() method

    Splits a string into an array based on a separator. split("") — each character separately.

    let arr = text.split("-"); // "a-b-c" → ["a","b","c"]
    .join() array method

    Glues array elements into a single string, inserting the specified separator between them.

    let str = arr.join("."); // ["a","b","c"] → "a.b.c"
    split→reverse→join chain

    Reversing text — a chain of three methods: split into characters, reverse the array, join back together.

    let rev = text.split("") .reverse() .join("");
    .replaceAll() method

    Replaces all occurrences of a given fragment with another text.

    let fixed = text.replaceAll("bug", "***"); // replaces EVERY occurrence
    .replace() method

    Replaces only the first occurrence of a given fragment. The rest stays unchanged.

    let fixed = text.replace("error", "OK"); // replaces ONLY the first one
    .slice() method

    Extracts a portion of a string from index start to end (excluding end). Indices start at 0.

    let part = text.slice(0, 4); // "JavaScript" → "Java"
    ⚡ Property vs Method

    Common student mistake! A property has no parentheses, a method always has ().

    ✓ text.length — property, NO parentheses
    ✓ text.toUpperCase() — method, parentheses required
    ✗ text.length() — ERROR!
    ✗ text.toUpperCase — ERROR! (missing parentheses)
