Metody klasy String

Interaktywny przegląd 11 metod i właściwości tekstowych używanych w lekcji „Input System — Turniej". Wpisz tekst w piaskownicę po lewej i obserwuj wyniki na żywo, albo testuj każdą metodę osobno na kartach.

trim() toUpperCase() toLowerCase() .length includes() split() join() reverse() replaceAll() replace() slice()

Piaskownica

    .trim() metoda

    Usuwa białe znaki (spacje, tabulatory) z początku i końca stringa. Nie zmienia środka tekstu.

    let clean = text.trim(); // " Ala " → "Ala"
    .toUpperCase() metoda

    Zwraca nowy string z wszystkimi literami zamienionymi na wielkie. Oryginał się nie zmienia.

    let big = text.toUpperCase(); // "ala" → "ALA"
    .toLowerCase() metoda

    Zwraca nowy string z wszystkimi literami zamienionymi na małe. Przydatne przed porównywaniem.

    let small = text.toLowerCase(); // "ALA" → "ala"
    .length właściwość

    Zwraca liczbę znaków w stringu (łącznie ze spacjami). Uwaga: to właściwość — bez nawiasów!

    let len = text.length; // "abc" → 3 (bez nawiasów!)
    .includes() metoda

    Sprawdza, czy string zawiera podany fragment. Zwraca true albo false. Rozróżnia wielkość liter!

    let found = text.includes("java"); // rozróżnia WIELKIE/małe!
    .split() metoda

    Rozbija string na tablicę według podanego separatora. split("") — każdy znak osobno.

    let arr = text.split("-"); // "a-b-c" → ["a","b","c"]
    .join() metoda tablicy

    Skleja elementy tablicy w jeden string, wstawiając między nie podany łącznik.

    let str = arr.join("."); // ["a","b","c"] → "a.b.c"
    split→reverse→join łańcuch

    Odwracanie tekstu — łańcuch trzech metod: rozbij na znaki, odwróć tablicę, sklej z powrotem.

    let rev = text.split("") .reverse() .join("");
    .replaceAll() metoda

    Zamienia wszystkie wystąpienia podanego fragmentu na inny tekst.

    let fixed = text.replaceAll("bug", "***"); // zamienia KAŻDE wystąpienie
    .replace() metoda

    Zamienia tylko pierwsze wystąpienie podanego fragmentu. Reszta zostaje bez zmian.

    let fixed = text.replace("error", "OK"); // zamienia TYLKO pierwsze
    .slice() metoda

    Wycina fragment stringa od indeksu start do end (bez end). Indeksy liczone od 0.

    let part = text.slice(0, 4); // "JavaScript" → "Java"
    ⚡ Właściwość vs Metoda

    Częsty błąd uczniów! Właściwość nie ma nawiasów, metoda zawsze ma ().

    ✓ text.length — właściwość, BEZ nawiasów
    ✓ text.toUpperCase() — metoda, nawiasy obowiązkowe
    ✗ text.length() — BŁĄD!
    ✗ text.toUpperCase — BŁĄD! (brak nawiasów)
    // Zapamiętaj: .length to JEDYNA // właściwość na tej ściądze. // Cała reszta to metody z ().
    Wskazówka: piaskownica po lewej reaguje na każdą zmianę tekstu — pokazuje wynik wszystkich metod jednocześnie. Karty pozwalają testować metody z własnymi parametrami. Każda metoda (oprócz .length) zwraca nową wartość — oryginał się nie zmienia.
