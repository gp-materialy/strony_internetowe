Métodos de la clase String

Un repaso interactivo de 11 métodos y propiedades de texto utilizados en la lección «Input System — Torneo». Escribe texto en el sandbox de la izquierda para ver resultados en vivo, o prueba cada método individualmente en las tarjetas.

Sandbox

    .trim() método

    Elimina los espacios en blanco (espacios, tabulaciones) del principio y final de un string. No cambia el medio.

    let clean = text.trim(); // " Ala " → "Ala"
    .toUpperCase() método

    Devuelve un nuevo string con todas las letras convertidas a mayúsculas. El original no cambia.

    let big = text.toUpperCase(); // "ala" → "ALA"
    .toLowerCase() método

    Devuelve un nuevo string con todas las letras en minúsculas. Útil antes de hacer comparaciones.

    let small = text.toLowerCase(); // "ALA" → "ala"
    .length propiedad

    Devuelve el número de caracteres del string (incluyendo espacios). Atención: es una propiedad — ¡sin paréntesis!

    let len = text.length; // "abc" → 3 (¡sin paréntesis!)
    .includes() método

    Comprueba si un string contiene un fragmento dado. Devuelve true o false. ¡Distingue mayúsculas y minúsculas!

    let found = text.includes("java"); // ¡distingue MAYÚSCULAS/minúsculas!
    .split() método

    Divide un string en un array según un separador. split("") — cada carácter por separado.

    let arr = text.split("-"); // "a-b-c" → ["a","b","c"]
    .join() método de array

    Une los elementos de un array en un solo string, insertando el separador indicado entre ellos.

    let str = arr.join("."); // ["a","b","c"] → "a.b.c"
    split→reverse→join cadena

    Invertir texto — una cadena de tres métodos: dividir en caracteres, invertir el array, unir de nuevo.

    let rev = text.split("") .reverse() .join("");
    .replaceAll() método

    Reemplaza todas las apariciones de un fragmento dado por otro texto.

    let fixed = text.replaceAll("bug", "***"); // reemplaza CADA aparición
    .replace() método

    Reemplaza solo la primera aparición de un fragmento dado. El resto queda sin cambios.

    let fixed = text.replace("error", "OK"); // reemplaza SOLO el primero
    .slice() método

    Extrae una porción del string desde el índice inicio hasta fin (sin incluir fin). Los índices empiezan en 0.

    let part = text.slice(0, 4); // "JavaScript" → "Java"
    ⚡ Propiedad vs Método

    ¡Error frecuente de los alumnos! Una propiedad no tiene paréntesis, un método siempre tiene ().

    ✓ text.length — propiedad, SIN paréntesis
    ✓ text.toUpperCase() — método, paréntesis obligatorios
    ✗ text.length() — ¡ERROR!
    ✗ text.toUpperCase — ¡ERROR! (faltan paréntesis)
    // Recuerda: .length es la ÚNICA // propiedad en esta chuleta. // Todo lo demás es un método con ().
